# 写作标准（操作版）

规则背下来没用，要能上手。这份文件给的是**动作**：怎么开头、证据从哪找、反常识怎么写、写坏了怎么改。

---

## 一、开头：十二种可用的开场

规则只有一条——**第一段必须让读者想知道"然后呢"**。结论开场等于把答案先给了，没人往下读。

轮换使用，同一批内容里不要连用同一种。

| # | 类型 | 例子 |
|---|---|---|
| 1 | 具体时刻 + 数字 | 2023 年 2 月，一个荷兰人上线了个给自拍生成写真的网站。第一周收入 5400 美元，五个月后单月 61800。 |
| 2 | 一次对话 | 上周有个做设计的朋友问我："客户要我报个价，我该按小时还是按项目？" |
| 3 | 一次失败带代价 | 他花了 8 万块买了个教训：合同里没写"修改次数上限"。 |
| 4 | 一个反常细节 | 这个 4000 人的社群，每天说话的只有 3 个人。 |
| 5 | 价格对比 | 同样的活，他收 8000，隔街那家收 800。两家都活着。 |
| 6 | 一份账单 | 他给我看后台：上个月流水 68 万，年底账上剩 1.2 万。 |
| 7 | 一个时间差 | 从注册公司到第一笔回款，他花了 11 个月，第 9 个月差点关门。 |
| 8 | 一句原话 | 他们说得很直接："我们不缺内容，我们不知道先看哪个。" |
| 9 | 一次现场 | 直播间在线 12 人，他讲了 90 分钟，结束后收到 3 条私信。 |
| 10 | 对照组 | 两个人同时起号。一个日更，一个周更。三个月后，日更那个停更了。 |
| 11 | 一份文件 | 那份合同的第 7 条写着："乙方须无条件配合甲方后续调整。" |
| 12 | 一个具体的提问 | 有人问："我这种一个人接活、没员工、没办公室的，算不算公司？" |

**不要这样开头：**

- ❌ 定价是每个创业者都要面对的核心问题。（结论）
- ❌ 随着 AI 技术的发展，越来越多的人开始……（时代背景）
- ❌ 在当今竞争激烈的市场环境下……（可以套在任何主题上）

判断法：把这句话换到另一篇文章里，如果毫无违和，它就不是开头，是废话。

## 二、证据：五种，以及去哪找

没有证据的判断一律删。这不是文风问题，是可信度问题。

### 第 1 种：官方文档 / 规范

最硬。有版本号、有发布日期、有原文可引。

- 语言 / 框架 / 工具：官方文档、Release Notes、RFC
- 协议：规范原文（如 MCP 的 JSON-RPC 定义、开源许可证全文）
- 平台规则：平台官方公告、开发者文档、帮助中心

写法：`按 <规范名> v<版本> 第 X 节，<原文要点>（<链接>）`

### 第 2 种：法规原文

条款号要写准，生效日期要写准。这是"敢下结论"的底气。

写法：`《公司法》（2024-07-01 施行）第 23 条第 3 款：<要点>`

注意：法律类内容篇首要加"不构成法律意见"。

### 第 3 种：公开数据

财报、招股书、平台公开披露、政府统计。第三方转述的数据要标"媒体二次整理"。

写法：`<主体> <年份> 年报披露：<数字>（自报，未经审计）`

### 第 4 种：当事人原话

访谈、公开演讲、播客、评论区。转述要标"大意"。

写法：`他原话是"<原话>"` 或 `大意是<转述>`

### 第 5 种：可当场演算的算式

不需要外部数据，读者自己能算。这类证据最有说服力，因为它可验证。

写法示例：

> CAC = 5000 元广告费 ÷ 20 个付费客户 = 250 元
> 客单价 199 元，首单毛利 120 元 → 首单回收率 48%，要 2.1 单才回本

**没有证据时怎么办：**
1. 去搜（WebSearch 取一手来源）
2. 换成"经验归纳，非统计结论"并说明样本来源
3. 删掉这个判断

**绝对不要：** 编造论文、编造访谈、编造精确到小数点的百分比。一旦被查出来，整库信誉归零。

## 三、反常识判断：五种句式

每篇必须有一个。不是"要重视 X"，而是"主流说 A，但实际是 B，因为 C"。

| # | 句式 | 例子 |
|---|---|---|
| 1 | 不是 A，是 B | 涨价掉客户，不是因为贵，是因为你没给他一个"留下的理由"。 |
| 2 | 越多越差 | 知识库写得越多死得越快——信息密度低到一定程度，检索成本超过重建成本。 |
| 3 | 你以为 X，其实 Y | 你以为在省钱，其实在买"三年不能涨价"的期权。 |
| 4 | 正确做法是不做 | 这个功能最正确的处理方式是删掉，不是优化。 |
| 5 | 行业里都在做但没人说 | 所有人都在算毛利率，没人算"每结果成本"，所以 AI 功能一做就亏。 |

**合格的判据：** 这句话能不能让一部分人不同意？如果不能，它就是正确的废话。

## 四、失败样本：三种来源

没有失败样本的内容，读者会觉得"你说得对，但我照做没用怎么办"。

| 来源 | 怎么用 | 注意 |
|---|---|---|
| 公开的失败复盘 | 引用具体项目、具体金额、具体时间 | 标注公开来源 |
| 反例推演 | "如果按 X 做，三个月后会怎样"，**要算账** | 标明是推演，不是真人真事 |
| 一线见闻 | "我见过一个团队……" | 匿名处理，不指向可识别的人 |

反例推演必须带数字，否则就变成"危言耸听"。示例：

> 假设你按 199 元定价、CAC 250 元、月流失 8%，那么稳态客户数 = 月新增 ÷ 0.08。月投 5000 元广告只能带来 20 个新客，稳态 250 个客户，MRR 约 5 万，扣掉广告和工具，剩下不到 2 万。这就是为什么低价 + 付费投放在一人公司里基本跑不通。

## 五、禁用词替换表

| 禁用 | 替换成 | 为什么 |
|---|---|---|
| 本质是 / 核心在于 | 直接说它是什么、怎么发生的 | "本质"是在替自己省事，跳过机制 |
| 底层逻辑 | 具体的因果链 | 同上，且已被用滥 |
| 赋能 / 抓手 / 形成闭环 | 谁在什么时候做了什么 | 这三个词没有对应动作 |
| 生态位 | 你在这个链条的哪一环、拿多少 | 同上 |
| 要点一 / 要点二 | 小标题写"事"，或不编号 | 编号是把思考外包给排版 |
| 首先 / 其次 / 最后 | 长短句混排，允许一句话成段 | 三段式排比是模板味最重的标志 |
| 在当今时代 / 随着 AI 的发展 | 删掉，直接从时间地点开始 | 时代背景开场 = 没有信息 |
| 值得一提的是 / 不得不说 | 删掉 | 纯填充 |
| 不仅…而且… / 既是…也是… | 拆两句，只留信息量大的那句 | 并列句通常有一半是凑数 |
| 让我们来看看 | 删掉 | 播报腔 |

**例外：** 被引号裹住的（`不用"赋能"`）、或前面有"不用/别用/避免"的，属于"教人别这么写"，不算违规。

## 六、三种粒度怎么选

同一个选题可以拆成两个单元。判断法：

| 如果你想说的 | 选 |
|---|---|
| 有一个完整案例 + 一套方法 + 一个反常识 | **深度篇**（1800–3000 字） |
| 有一个判断 + 三条动作 | **标准篇**（900–1500 字） |
| 只有一句结论 + 三个判据，且能独立成立 | **速查卡**（200–400 字） |

**速查卡不是摘要。** 摘要依赖原文才看得懂，卡必须能单独立住。写法：

```
场景一句话 → 三问（每问一个判据）→ 一句结论
```

示例（知识库自查卡）：

> **用的时候：** 觉得自己的库"建了但没用起来"。
> **三问：** 1. 最近一个月从库里取到过东西吗？ 2. 文件夹是按"我要解决什么问题"分的吗？ 3. 随便抽一个问题，2 分钟内能用库答上吗？
> **一句结论：** 库的价值不在装了多少，在能被多少个问题叫出来。

## 七、自查：写完先过这四关

1. **抹名字测试。** 把作者名抹掉，这段话放到任何一篇公众号里违和吗？不违和 = 废的。
2. **证据测试。** 每个小标题下有没有至少一个数字/时间/原话/算式？逐个数。
3. **反常识测试。** 有没有一句话会让一部分人不高兴？没有就补。
4. **动作测试。** 读者看完今晚能做什么？如果答案是"提高认知"，重写。

四关全过才算成稿。任何一关过不了，返修，不要交。
