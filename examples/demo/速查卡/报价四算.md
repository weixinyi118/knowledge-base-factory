# 报价四算

**用的时候：** 有人来问价，你不知道该报多少。

**算四个数，不要算粉丝数：**

1. **占用你几天。** 从接需求到交付完成，含改稿和沟通。很多人算完发现时薪不到 50。
2. **替代成本。** 对方自己做要花多少。低于这个数，他反而不敢用。
3. **可复用性。** 能不能再卖一次。不能，独占的钱要收进来。
4. **失败率。** 商单播放通常只有自然内容的 40%，不确定性要加价 30%–50%。

**两个套餐胜过八个报价：** 轻的写明"不含改稿"，重的写明"含授权"。可选项越多，对方越会挑最便宜的然后要最多的服务。

**一句结论：** 第一单可以便宜，但报价单上必须写"首单体验价"。
